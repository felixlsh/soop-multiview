# SOOP Lens by felix 2.2.1

여러 SOOP 방송과 채팅을 원하는 비율로 보는 Windows 앱입니다. 최대 9개 방송, 배치 자율, 개별 영상·채팅 조절, 선택 기록과 알림을 제공합니다.

## 2.2.1 개선 (2026-10-03)

- 분리 창에서 여러 방송 보기와 창 위치·크기·배치 자동 복원
- 관측 목록 유지, 관측 전용 계정 등록, 최근 관측·검색·정렬·방송별 관계와 조회 진단
- 제재 기록은 마지막 채팅 1개 기본 표시, 펼치면 전체 수신 대화와 확인된 채금 처리자 표시
- 후원 수량은 한 줄·내용에 맞는 너비, 통합 채팅 검색과 미니 필터 버튼·아코디언
- 새 게시글 알림은 블루 헤더로 구분
- 새 방송 입장·재방송·재실행은 기본 음소거, 사용자가 선택한 소리는 새로고침에서도 유지
- 핀 즐겨찾기 LIVE 감지는 5초 입장 확인 카드로 안내, 선택하지 않으면 건너뛰기·제목 드래그 지원

## 2.1.6 개선 (2026-10-03)

- 즐겨찾기 종 버튼으로 방송국 게시글 알림 등록, 새 글·읽음·키워드·사진 확대·본문 링크·모두 읽음
- 알림 잠시 끄기, 최근 닫힌 방송과 기록 확인·재입장, 설정 백업 미리보기·복원
- 공식 방송 종료 판단 보완과 기존 대기·복구·기록 보존 정책 유지

## 설치와 데이터

Windows 10/11 x64용 설치형과 포터블, SHA-256 체크섬을 Releases에서 제공합니다. 코드 서명되지 않은 배포본으로 Windows 게시자 확인 안내가 나타날 수 있습니다.

기존 앱을 종료하고 새 설치형을 실행해 업데이트합니다. 설치 식별자와 `%APPDATA%\SOOP Multiview` 데이터 경로는 유지합니다. 설치형과 포터블은 기본 설정을 공유합니다. 새 버전 안내를 지원하며 자동 설치는 제공하지 않습니다.

전체 임시 기록은 10GiB 한도이며 입장 회차별 전체 채팅 1GiB, 선택 기록 64MiB 한도를 함께 적용합니다. 방송을 닫아도 앱 종료까지 남기고, 재입장은 별도 회차로 저장합니다. 기본 조회는 모든 회차를 함께 보여주며 후원 누적과 제재 대화는 해당 회차를 기준으로 합니다. 명시적 기록 지우기·로그아웃·앱 종료 시 삭제하고 강제 종료 잔여 파일은 다음 시작 때 정리합니다. 한도 도달 시 기존 기록을 유지하고 새 보관을 중단합니다. SQLite 작업 저널은 일시적으로 추가 공간을 사용할 수 있습니다.

실제 로그인 계정 즐겨찾기 연동은 사용자 실사용으로 확인했습니다. 앱에서 실제 계정으로 9개 시청 및 Windows 알림 표면 클릭은 미검증입니다. 포터블은 앱 알림함을 제공합니다. 스트리머 조회는 부분 대조이며 참고 즐겨찾기 수는 실시간 수치가 아닙니다. 광고 차단은 현재 확인된 요청·배너에만 적용됩니다. 자세한 범위와 검증은 변경 내역을 확인하세요.

이 저장소는 다운로드 페이지와 배포 파일을 제공합니다. 앱 소스 저장소가 아닙니다. SOOP 공식 제품이 아니며 공식 로그인·시청 제한을 따릅니다. 문제 제보에 비밀번호·쿠키·토큰·개인 채팅 원문을 포함하지 마세요.
