# SOOP Multiview

여러 SOOP 방송과 채팅을 한 화면에서 보는 비공식 Windows 앱입니다.

**[다운로드 페이지](https://felixlsh.github.io/soop-multiview/)** · **[0.3.0 릴리스](https://github.com/felixlsh/soop-multiview/releases/tag/v0.3.0)**

이 저장소는 다운로드 페이지와 Windows 배포 파일을 제공합니다. 앱 소스 저장소가 아닙니다.

## 0.3.0 테스트 릴리스

- 최대 4개 방송, 균등 분할·스포트라이트·양쪽 메인, 배치 프리셋과 순서 변경
- 입장 시 스크린 모드·공식 채팅 표시·기록 수신 기본 활성화
- LIVE 목록·검색·카테고리, 즐겨찾기 핀·상태·선택적 알림과 자동 입장
- 지정 키워드·계정 채팅, 후원, 알림 원문만 입장부터 퇴장까지 로컬 임시 보관
- 복수 방송·포함/제외 단어·ID 정확 일치 필터와 저장 프리셋
- 최대 20개 알림 규칙, 앱 알림함·읽음·원문·묶음 보기
- 설치형 Windows 알림(기본 꺼짐), 미리보기·소리·빈도 제한; 포터블은 앱 알림함
- 후원 종류·계정·최소 수량 필터와 전체 시청 세션의 방송별 관측 건수
- 네트워크 페이지 로드 실패 시 제한된 횟수의 자동 재연결

Windows 10/11 x64용입니다. **코드 서명되지 않은 테스트 배포본**으로 Windows의 게시자 확인 안내가 나타날 수 있습니다. 설치 파일과 포터블 파일, SHA-256 해시를 Releases에서 제공합니다.

설정과 세션은 `%APPDATA%\SOOP Multiview`에 저장됩니다. 설치본과 포터블이 같은 설정을 공유합니다. 업데이트는 새 버전을 직접 다운로드해 적용합니다.

선택 기록은 방송 제거·로그아웃·정상 종료 시 삭제하며, 강제 종료 시 다음 시작 때 정리합니다. 모든 채팅을 저장하지 않습니다.

실제 Windows 알림 표면 클릭과 로그인 계정의 즐겨찾기 가져오기는 아직 검증하지 않았습니다. 후원 표시는 수신 이벤트이며 결제·정산 내역을 의미하지 않습니다. 관심 계정은 부분 확인 결과이며, 채금·영구 밴이나 스트리머 자격은 판정하지 않습니다. 공식 로그인과 시청 제한을 그대로 따릅니다.

SOOP의 공식 제품이 아닙니다. 문제 제보에 비밀번호·쿠키·토큰·개인 채팅 원문을 포함하지 마세요.

30분 관측에서는 3개 방송의 영상 진행을 확인했고 1개는 초기화 상태였습니다. 4개 방송 모두의 30분 연속 재생은 미입증입니다. [자세한 검증과 제한](RELEASE_NOTES.md)을 확인하세요.
