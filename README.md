# SOOP Lens by felix 1.0.8

여러 SOOP 방송과 채팅을 원하는 비율로 보는 Windows 앱입니다. 최대 9개 방송, 배치 자율, 개별 영상·채팅 조절, 선택 기록과 알림을 제공합니다.

## 1.0.8 개선 (2026-09-25)

- 영상 더블클릭 전체화면 복구, 균등 분할의 메인 미선택 상태에서도 해당 방송만 자동 최대 1080p 적용
- 많은 방송을 열었을 때 번호 카드 스크롤바와 LIVE 입장 항목 음영 개선
- 일반·영상 별풍선 및 도전·대결 미션 한 건 1,000개 이상 알림과 움직이는 glow 강조, 기준값 설정
- 본문이 없는 후원에 같은 계정의 첫 후속 채팅 연결. 미션 정산 수량과는 별개로 수신 알림 수량을 표시
- 설치부터 전체 기능·데이터 보관·제한을 설명하는 [상세 사용법](USER_GUIDE.md) 제공
## 1.0.7 개선 (2026-09-25)

- 조회 메뉴 바깥 클릭 시 닫힘, LIVE·즐겨찾기 호버 미리보기 복구
- 제재 기록에서 방송명·강퇴/채금 횟수·제재 직전 채팅을 즉시 확인
- 5~9개 균등 분할에서 영상 공간을 위해 채팅 표시만 숨기며 연결·수신·보관은 지속; 다른 배치에서 복원
- 즐겨찾기 OFF 프로필 가로 채움과 별풍선 상세 중복 문구 제거

## 1.0.6 개선 (2026-09-25)

- 조회 메뉴가 방송 영역 크기를 바꾸지 않는 오른쪽 오버레이로 열리고, 방송별 정보 헤더는 호버 때 영상 위에 표시
- 방송 보고 있는 스트리머의 아이콘·즐겨찾기 표시와 시청자 수 안내 개선, 매니저 채팅 선택 보관
- 별풍선 종류별 배지·열혈 표시·방송명과 후원자별 종류별 시점 누적, 오기입 가능성이 있는 후속 채팅 추정 연결 제거
- 공식 채팅의 최신 위치 자동 유지와 수동으로 이전 채팅을 읽을 때의 위치 보존

## 1.0.5 개선 (2026-09-25)

- 최상단 방송 번호 카드에는 볼륨·닫기, 각 방송 헤더에는 화질·시청자 수·방송시간과 개별 조작 표시
- 별풍선·제재 기록 목록과 아이콘 개선, 별도 제재 메뉴 추가
- 열린 방송 전체의 관측 스트리머와 LIVE 전체 검색 지원

## 1.0.4 수정 배포 (2026-09-25)

버전 번호와 다운로드 파일명을 유지한 수정본입니다. 이전 1.0.4 설치본에는 아래 개선이 적용되지 않으므로 새 설치형을 다시 실행하세요. 체크섬은 변경 내역에서 확인할 수 있습니다.

- 상단 즐겨찾기 메뉴와 패널 헤더에 같은 LIVE 수 표시
- 즐겨찾기 행 높이 약 1.2배, 방송명·상태 글자 확대
- OFF 프로필을 잘리지 않는 사각형으로 표시하고 움직이는 원본 이미지 유지
- 고정 핀은 테두리 없이 금색 채움으로 구분

## 설치와 데이터

Windows 10/11 x64용 설치형과 포터블, SHA-256 체크섬을 Releases에서 제공합니다. 코드 서명되지 않은 배포본으로 Windows 게시자 확인 안내가 나타날 수 있습니다.

기존 앱을 종료하고 새 설치형을 실행해 업데이트합니다. 설치 식별자와 `%APPDATA%\SOOP Multiview` 데이터 경로는 유지합니다. 설치형과 포터블은 기본 설정을 공유하며 자동 업데이트는 제공하지 않습니다.

전체 일반 채팅을 방송별 최대 1GiB까지 별도 로컬 임시 보관합니다. 목록에는 기존 선택 조건에 맞는 기록을 보여줍니다. 전체 임시 보관과 선택 기록은 방송 제거·로그아웃·정상 종료 시 삭제하며 강제 종료 잔여 파일은 다음 시작 때 정리합니다. 선택 기록은 방송별 64MiB 한도가 있으며 수신·저장 오류에 따른 제한이 있습니다.

실제 로그인 계정 즐겨찾기 연동은 사용자 실사용으로 확인했습니다. 앱에서 실제 계정으로 9개 시청 및 Windows 알림 표면 클릭은 미검증입니다. 포터블은 앱 알림함을 제공합니다. 스트리머 조회는 부분 대조이며 참고 즐겨찾기 수는 실시간 수치가 아닙니다. 광고 차단은 현재 확인된 요청·배너에만 적용됩니다. 자세한 범위와 검증은 변경 내역을 확인하세요.

이 저장소는 다운로드 페이지와 배포 파일을 제공합니다. 앱 소스 저장소가 아닙니다. SOOP 공식 제품이 아니며 공식 로그인·시청 제한을 따릅니다. 문제 제보에 비밀번호·쿠키·토큰·개인 채팅 원문을 포함하지 마세요.
