01 / 자유로운 배치

원하는 방송, 원하는 비율

단일 보기·분할·스포트라이트·양쪽 메인. 방송 사이와 영상·채팅 사이 경계를 따로 조절하고 배치를 저장하세요.

02 / 빠른 조작

한 번에 전환하고 조절

번호 클릭으로 하나만 보기와 이전 배치 복원, 드래그로 순서 변경. 영상 위 휠은 볼륨을 5%씩 조절합니다.

03 / 방송 탐색

미리 보고 바로 입장

LIVE·즐겨찾기 썸네일 미리보기, 고정 정렬과 방송 상태 확인. 등록한 스트리머의 시청 여부를 부분 조회합니다.

04 / 선택 기록

필요한 내용만 남기기

지정 키워드·계정 채팅, 후원, 알림과 제재 기록을 입장부터 퇴장까지. 전체 채팅은 제재 계정의 대화 조회용으로 별도 임시 보관합니다.

05 / 알림과 별풍선

놓치고 싶지 않은 순간

키워드 알림함과 설치형 Windows 알림. 별풍선 본문과 종류별 누적, 강퇴·채팅 금지도 함께 확인하세요.

기존 사용자는 어떻게 업데이트하나요?

기존 앱을 종료하고 새 설치형을 실행하세요. 기존 즐겨찾기·배치·필터·알림 설정을 이어갑니다. 설치 식별자와 %APPDATA%\SOOP Multiview 경로는 유지하며 설치형·포터블은 기본 설정을 공유합니다. 자동 업데이트는 제공하지 않습니다.

채팅 기록은 어디까지 보관하나요?

전체 일반 채팅은 방송별 1GiB까지 별도 로컬 임시 보관하고, 기본 목록에는 조건에 맞는 채팅·후원·알림·제재 기록을 보여주며 검색은 이 시청의 전체 임시 채팅을 조회합니다. 입장부터 슬롯을 닫을 때까지 보관합니다. 로그아웃·정상 종료에도 삭제하며 강제 종료 잔여 파일은 다음 시작 때 정리합니다. 선택 기록은 방송별 64MiB이며 전체 보관 한도 도달 시 이전 기록을 유지하고 새 보관 중단을 안내합니다.

기능에 어떤 제한이 있나요?

독립 프로필 3개에 최대 4개씩, 앱 전체 9개 방송을 지원합니다. 기존 로그인·즐겨찾기는 프로필 1에 유지되며 추가 프로필은 필요할 때 각각 로그인합니다. 스트리머 조회는 부분 대조이며 참고 즐겨찾기 수는 실시간 수치가 아닙니다. 광고 차단은 현재 확인된 요청·배너에 적용되고 영상 자체의 광고는 제거하지 않습니다. 공식 로그인·시청 제한을 따릅니다.

Windows 알림과 검증 범위는?

Windows 알림은 설치형에서 선택적으로 켤 수 있으며 포터블은 앱 알림함을 사용합니다. 계정 즐겨찾기는 사용자 실사용 확인을 완료했습니다. 실제 계정으로 앱 9개 동시 시청과 Windows 알림 표면 클릭은 미검증입니다. 공개 방송 관측과 자동 검사 결과는 릴리스 노트에 구분해 제공합니다.
