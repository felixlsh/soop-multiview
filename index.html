업데이트는 이 페이지에서 새 버전을 받아 설치하는 방식입니다. 설치본과 포터블은 같은 PC의 사용자 설정을 공유합니다.

처음 시작하기

  1. 설치 파일을 설치하거나 포터블 파일을 실행합니다.
  2. 방송 추가에 SOOP 주소 또는 스트리머 ID를 입력합니다.
  3. 소리를 들을 방송을 선택합니다. 새 방송은 음소거로 열립니다.
  4. 로그인이 필요한 경우 앱의 SOOP 로그인에서 공식 화면으로 로그인합니다.

이번 버전의 범위

  • 최대 4개 방송. PC 성능·방송 화질·회선에 따라 재생 품질이 달라집니다.
  • LIVE 검색은 불러온 목록에 적용됩니다. 더 불러오기로 범위를 넓힐 수 있습니다.
  • 채팅 기록은 최근 30분, 방송당 최대 2,000개를 메모리에 보관합니다.
  • 관심 계정 확인은 부분 결과입니다. 전체 시청자나 스트리머 자격을 판정하지 않습니다.
  • 계정 즐겨찾기 가져오기의 실제 로그인 계정 검증은 보류 중입니다.

자주 묻는 내용

SOOP 공식 프로그램인가요?

개인이 만든 비공식 보조 프로그램이며 SOOP의 공식 제품이 아닙니다. 공식 플레이어를 사용하며 로그인·인증·광고·구독과 시청 제한은 SOOP 정책을 따릅니다.

로그인 정보와 채팅은 어디에 저장되나요?

앱 설정과 SOOP 세션은 이 PC의 %APPDATA%\SOOP Multiview에 저장됩니다. 별도의 앱 서버로 계정이나 채팅을 전송하지 않습니다. 영상·로그인·LIVE 조회에는 SOOP와 관련 서비스의 통신이 사용됩니다. 앱에서 수집한 채팅 기록은 파일에 저장하지 않으며 방송 삭제 또는 앱 종료 시 사라집니다.

기존 개발 버전의 설정을 옮길 수 있나요?

앱을 모두 종료한 뒤 기존 프로젝트의 .runtime\user-data\state.json을 새 사용자 데이터 폴더의 state.json으로 복사하면 됩니다. 기존 파일이 있다면 먼저 백업하세요. 로그인 세션은 옮기지 않으며 새 앱에서 로그인합니다.

문제를 발견했어요.

앱의 재생 진단으로 상태를 확인할 수 있습니다. 문제 제보에 앱 버전과 재현 방법을 남겨 주세요. 비밀번호·쿠키·토큰·개인 채팅 원문은 올리지 마세요.
